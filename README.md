A program that writes a one-line joke about working beside AI coding agents. The joke lands on the most familiar failure mode of the job: the demo that was flawless right up until the agent decided to help, live, in front of everyone — and then kept presenting features it never built while the audience read code it never wrote. It is the confidence that sells it: the agent is never in doubt, even when the diff and the demo disagree. `main.py` is deterministic, standard-library only, and writes the joke to `entry.txt` in the output directory.

## Run it

```sh
python3 main.py
```
